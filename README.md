# DLPapp

Простое приложение для Windows 10/11 x64 на Python и Tkinter:
**ссылка → проверка видео → выбор доступного качества → скачивание**.

Готовый `DLPapp.exe` запускается без установки Python, FFmpeg, yt-dlp и Deno.
Его можно перемещать между папками и дисками после закрытия приложения.
Видео сохраняются в папку `Downloads` рядом с EXE. Эта папка должна быть доступна
для записи. Приложение не привязано к диску D и не зависит от рабочей папки запуска.

## Возможности

- Проверка ссылки без скачивания видео.
- Выбор разрешений, которые сообщил yt-dlp, например 720p и 1080p.
- Загрузка видео со звуком, если у исходного видео есть аудиодорожка.
- Прогресс, скорость, оставшееся время и отмена.
- Открытие папки с результатом.
- Фоновые операции: окно остаётся отзывчивым при проверке и скачивании.

Приложение предназначено для отдельных видео; плейлисты и прямые эфиры
не поддерживаются. Раздельные видео и звук объединяются в MKV без перекодирования.
Единые потоки сохраняют исходный контейнер. Выбранное разрешение не заменяется
более низким автоматически. Отмена оставляет частичные файлы для повторной загрузки.

## Собрать свой EXE

**Только на компьютере разработчика** нужны Windows 10/11, Python 3.11+ x64
с Tkinter и интернет. Пользователям готового EXE Python не нужен.

Распакуйте исходники, откройте терминал в папке проекта и выполните:

```powershell
python build_exe.py
```

Или дважды нажмите `build_windows.bat`.

`build_exe.py` самостоятельно:

1. Создаёт изолированную среду `.build-env` и устанавливает туда PyInstaller.
2. Запускает тесты.
3. При отсутствии инструментов скачивает официальные Windows-версии yt-dlp,
   FFmpeg, ffprobe и Deno в `tools`. Проверяет запуск каждого инструмента.
4. Упаковывает интерфейс, Python и инструменты в один EXE с помощью PyInstaller.
5. Проверяет наличие Windows-файла и выводит путь к результату.

Результат:

```text
 dist/DLPapp.exe
```

Передавайте пользователю **только этот EXE**. Файлы из `.build-env`, `build`
и `tools` отдельно передавать не требуется. Во время запуска EXE распаковывает
встроенные компоненты во временную папку, поэтому открытие может занять несколько секунд.
Обычный выход удаляет временные компоненты; скачанные видео остаются рядом с EXE.

Чтобы обновить инструменты и заново собрать EXE:

```powershell
python build_exe.py --refresh-tools
```

Имя приложения задаётся константой `APP_NAME` в `build_exe.py`. Заголовок окна
и надпись внутри интерфейса можно изменить отдельно в `app.py`.

## Запуск исходников

Подготовьте Windows-инструменты, затем запустите интерфейс:

```powershell
python setup_tools.py
python app.py
```

Для самого интерфейса сторонние Python-пакеты не нужны: Tkinter входит
в обычную установку Python для Windows. PyInstaller используется только для сборки.

## Архитектура

| Файл | Назначение |
| --- | --- |
| `assets/` | Логотип SVG/PNG и значок Windows ICO. |
| `app.py` | Окно Tkinter, состояния интерфейса, фоновые задачи, запуск процессов, прогресс и отмена. |
| `core.py` | Проверка URL, переносимые пути, список качеств, команды yt-dlp и разбор прогресса. |
| `setup_tools.py` | Скачивание официальных Windows-инструментов, проверка SHA-256 при наличии digest в GitHub API, распаковка и запись `tools/versions.json`. |
| `build_exe.py` | Подготовка среды, тесты и сборка одного переносимого EXE. |
| `build_windows.bat` | Удобный запуск `build_exe.py` двойным щелчком. |
| `tests/` | Проверка URL, качеств, путей и работы фонового процесса без обращения к сайтам. |
| `THIRD_PARTY.md` | Источники и лицензии сторонних компонентов. |
| `.gitignore` | Исключение сред, инструментов, загрузок и результатов сборки из Git. |
| `.github/workflows/build.yml` | Ручная сборка EXE в GitHub Actions на Windows. |

### Проверка видео

`app.py` получает ссылку → `core.py` проверяет её и формирует команду → отдельный
поток запускает yt-dlp с `--dump-single-json` и `--skip-download` → yt-dlp возвращает
JSON → `core.py` выбирает уникальные разрешения → окно показывает их пользователю.

### Скачивание

После выбора качества `core.py` формирует точный селектор разрешения. yt-dlp
скачивает потоки, FFmpeg при необходимости объединяет видео и звук. Deno используется
yt-dlp для выполнения JavaScript при работе с поддерживаемыми сайтами.

Рабочий поток помещает события в `queue.Queue`. Главное окно регулярно читает
очередь через `after()` и обновляет виджеты. Рабочий поток не обращается к Tkinter
напрямую. При отмене на Windows завершается дерево процесса yt-dlp и его дочерние процессы.
Сообщение «Готово» появляется после завершения процесса и проверки существования файла.

### Переносимость

`core.app_dir()` определяет папку готового приложения через `sys.executable`.
В Python-версии используется папка исходника. Встроенные инструменты находятся
через `sys._MEIPASS`, который устанавливает PyInstaller. Поэтому временные инструменты
и постоянная папка `Downloads` имеют разные пути.

Ранее предоставленный готовый EXE использует упаковку SFX с переносимым Python.
Этот комплект исходников предназначен для самостоятельной сборки через PyInstaller;
полученный EXE также содержит всё необходимое в одном файле.

## Тесты

Из папки проекта:

```powershell
python -m unittest discover -s tests -v
```

Тесты не обращаются к YouTube. Они проверяют обработку данных и локальные процессы.
Проверены 11 тестов и создание окна в Linux. Сборка через `build_exe.py`
на настоящей Windows в текущей среде не выполнялась.

## GitHub Actions

Загрузите содержимое папки проекта в корень репозитория.
Откройте **Actions → Windows portable EXE → Run workflow**.
После успешного выполнения скачайте `DLPapp-Windows-x64` из **Artifacts**.
Внутри будет `DLPapp.exe`. Рабочая среда Python предоставляется самим GitHub Actions.

## Лицензия

Лицензия вашего проекта в этот комплект не добавлена. Сохраните свою существующую
`LICENSE`, `LICENSE.txt` или `LICENSE.md` в корне проекта. Сборщик включит её
в EXE, не изменяя содержимое. `.gitignore` не исключает эти файлы.

Лицензии сторонних инструментов действуют отдельно; см. `THIRD_PARTY.md`.

## Ограничения

Приватные видео, требование входа, региональные ограничения, проверка бота
и изменения сайтов могут мешать скачиванию. Поддержка cookies не реализована.
Приложение покажет ошибку yt-dlp. Во время объединения потоков прогресс может
оставаться на 100% — дождитесь сообщения «Готово».
